#FACEPROJECTNYC

Keywords:

Instagram, javascript, api, Washington Square Park, strangers, street art, street hacking

Project website:

http://faceproject.nyc/

Collaborators:

This project was made in collaboration with Miri Park and Douglas Tran. 

Description:

#FaceProjectNYC was a public installation set in Washington Square Park in New York City. Participants were asked to Instagram a photo of their face using the hast tag: #FaceProjectNYC. Over the course of two weeks we collected faces from all over the world: Jakarta, London, Dubai, Los Angeles, and Beirut. The faces were then projected onto the face of the Arch in the park on October 24th, 2014. I helped to write the Javascript code that pulled the photos from the Instagram API and the front end code that was used to cycle through all the photos on our website. Our power source for this project came from a hacked streetlamp and a lot of ingenuity!
